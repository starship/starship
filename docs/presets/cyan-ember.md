# Cyan Ember Preset

Cyan Ember is a vibrant two-line Powerline-style preset inspired by [Gruvbox Rainbow](./gruvbox-rainbow.md). It combines warm brown and ember tones with bold cyan and turquoise accents.

The preset displays directory information, Git branch and status, programming language runtimes, Docker context, and time.

![Screenshot of Cyan Ember preset](/presets/img/cyan-ember.png)

### Prerequisites

- A [Nerd Font](https://www.nerdfonts.com/) installed and enabled in your terminal

### Configuration

```sh
starship preset cyan-ember -o ~/.config/starship.toml
```
