# Deep Context Preset

Deep Context builds on the [Nerd Font Symbols](./nerd-font.md) preset with complete paths
from the repository root and a compact `user@host` identity in SSH sessions. It keeps local
prompts clean while preserving context in deeply nested projects and remote shells.

![Screenshot of Deep Context preset](/presets/img/deep-context.png)

### Prerequisite

- A [Nerd Font](https://www.nerdfonts.com/) installed and enabled in your terminal

### Configuration

```sh
starship preset deep-context -o ~/.config/starship.toml
```
