# Алдын ала орнатылған баптаулар (Presets)

Мұнда Starship қауымдастығы ұсынған дайын конфигурациялық үлгілер жинақталған.
Егер сіз де өз үлгіңізбен бөліскіңіз келсе, осы файлды жаңартып, [PR жіберіңіз](https://github.com/starship/starship/edit/main/docs/presets/README.md)! 😊

Кез келген үлгіні қалай қолдану керектігі туралы толық мәлімет алу үшін суретіне басыңыз.

## [Nerd Font Symbols](./nerd-font.md)

Бұл үлгі әр модульдің таңбаларын Nerd Font белгішелеріне ауыстырады.

[![Nerd Font Symbols үлгісінің скриншоты](/presets/img/nerd-font-symbols.png "Nerd Font Symbols үлгісін көру үшін басыңыз")](./nerd-font)

## [No Nerd Fonts](./no-nerd-font.md)

Бұл үлгі промпттың ешбір жерінде Nerd Font таңбалары қолданылмайтындай етіп бірнеше модульдің белгішелерін өзгертеді.

> [!TIP]
> Бұл үлгі [Starship-тің болашақ шығарылымында](https://github.com/starship/starship/pull/3544) әдепкі баптауға айналады.

[No Nerd Font үлгісін көру үшін басыңыз](./no-nerd-font)

## [Bracketed Segments](./bracketed-segments.md)

Бұл үлгі барлық кірістірілген модульдердің пішімін өзгертіп, әдепкі Starship сөздерінің ("via", "on", т.б.) орнына әр сегментті жақшалар ішінде көрсетеді.

[![Bracketed Segments үлгісінің скриншоты](/presets/img/bracketed-segments.png "Bracketed Segments үлгісін көру үшін басыңыз")](./bracketed-segments)

## [Plain Text Symbols](./plain-text.md)

Бұл үлгі әр модульдің белгішелерін қарапайым мәтінге ауыстырады. Егер сіздің терминалыңызда Юникод (Unicode) қолдауы болмаса өте ыңғайлы.

[![Plain Text Symbols үлгісінің скриншоты](/presets/img/plain-text-symbols.png "Plain Text Symbols үлгісін көру үшін басыңыз")](./plain-text)

## [No Runtime Versions](./no-runtimes.md)

Бұл үлгі бағдарламалау тілдері мен орталарының нұсқаларын жасырады. Егер сіз контейнерлерде немесе виртуалдандырылған орталарда жұмыс істесеңіз — бұл үлгі сізге арналған!

[![No Runtime Versions үлгісінің скриншоты](/presets/img/no-runtime-versions.png "No Runtime Versions үлгісін көру үшін басыңыз")](./no-runtimes)

## [No Empty Icons](./no-empty-icons.md)

Бұл үлгі қажетті құралдар жиынтығы анықталмаған жағдайда бос белгішелерді көрсетпейді.

[![No Empty Icons үлгісінің скриншоты](/presets/img/no-empty-icons.png "No Empty Icons үлгісін көру үшін басыңыз")](./no-empty-icons.md)

## [Pure Prompt](./pure-preset.md)

Бұл үлгі [Pure](https://github.com/sindresorhus/pure) промптының сыртқы көрінісі мен жұмыс істеу мәнерін қайталайды.

[![Pure үлгісінің скриншоты](/presets/img/pure-preset.png "Pure Prompt үлгісін көру үшін басыңыз")](./pure-preset)

## [Pastel Powerline](./pastel-powerline.md)

Сондай-ақ ол Starship ішінде каталогтар жолын ауыстырудың қалай жұмыс істейтінін көрсетеді.

[![Pastel Powerline үлгісінің скриншоты](/presets/img/pastel-powerline.png "Pastel Powerline үлгісін көру үшін басыңыз")](./pastel-powerline)

## [Tokyo Night](./tokyo-night.md)

[![Tokyo Night үлгісінің скриншоты](/presets/img/tokyo-night.png "Tokyo Night үлгісін көру үшін басыңыз")](./tokyo-night)

## [Gruvbox Rainbow](./gruvbox-rainbow.md)
