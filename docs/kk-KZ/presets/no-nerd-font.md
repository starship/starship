# No Nerd Fonts үлгісі

Бұл үлгі таңбаларды тек эмодзи және powerline жиынтықтарымен ғана шектейді.

Бұл тіпті Nerd Font қарпі орнатылмаған жағдайда да барлық модульдердің белгішелерін дұрыс көруге мүмкіндік береді.

Бұл үлгі Starship-тің болашақ шығарылымында әдепкі баптауға айналады.

### Баптау

```sh
starship preset no-nerd-font -o ~/.config/starship.toml
```
