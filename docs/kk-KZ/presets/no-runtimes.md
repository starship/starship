# No Runtime Versions үлгісі

Бұл үлгі бағдарламалау тілдері мен орталарының нұсқаларын жасырады. Егер сіз контейнерлерде немесе виртуалдандырылған орталарда жұмыс істесеңіз — бұл үлгі сізге арналған!

![No Runtime Versions үлгісінің скриншоты](/presets/img/no-runtime-versions.png)

### Баптау

```sh
starship preset no-runtime-versions -o ~/.config/starship.toml
```
