# Plain Text Symbols үлгісі

Бұл үлгі әр модульдің белгішелерін қарапайым мәтінге ауыстырады. Егер сіздің терминалыңызда Юникод (Unicode) қолдауы болмаса өте ыңғайлы.

![Plain Text Symbols үлгісінің скриншоты](/presets/img/plain-text-symbols.png)

### Баптау

```sh
starship preset plain-text-symbols -o ~/.config/starship.toml
```
