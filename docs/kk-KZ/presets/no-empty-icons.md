# No Empty Icons үлгісі

Егер құралдар жиынтығы файлдары табылса, құрал белгішесі көрсетіледі. Егер оның нұсқасын анықтау үшін құрал жиынтығы табылмаса, белгіше көрсетілмейді. Бұл үлгі белгішені тек құрал жиынтығы туралы ақпаратты анықтау мүмкін болған кезде ғана көрсететіндей өзгертеді.

![No Empty Icons үлгісінің скриншоты](/presets/img/no-empty-icons.png)

### Баптау

```sh
starship preset no-empty-icons -o ~/.config/starship.toml
```
