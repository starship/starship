# Jetpack үлгісі

Бұл [geometry](https://github.com/geometry-zsh/geometry) және [spaceship](https://github.com/spaceship-prompt/spaceship-prompt) промпттарынан шабыттанған псевдо-минималистік үлгі.

> Jetpack терминалдың түстер тақырыбын қолданады.

![Jetpack үлгісінің скриншоты](/presets/img/jetpack.png)

### Алғышарттар

- [`right-prompt`](https://starship.rs/kk-KZ/advanced-config/#enable-right-prompt) қолдауы бар қабықшаны (shell) талап етеді.
- [Jetbrains Mono](https://www.jetbrains.com/lp/mono/) қарпін пайдалану ұсынылады.

### Баптау

```sh
starship preset jetpack -o ~/.config/starship.toml
```
