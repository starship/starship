# Nerd Font Symbols үлгісі

Бұл үлгі әр модульдің таңбаларын Nerd Font белгішелеріне ауыстырады.

![Nerd Font Symbols үлгісінің скриншоты](/presets/img/nerd-font-symbols.png)

### Алғышарттар

- Терминалыңызда [Nerd Font](https://www.nerdfonts.com/) қарпі орнатылған және қосылған болуы қажет (мысалда Fira Code Nerd Font қарпі қолданылған)

### Баптау

```sh
starship preset nerd-font-symbols -o ~/.config/starship.toml
```
