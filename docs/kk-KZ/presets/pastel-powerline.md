# Pastel Powerline үлгісі

Бұл үлгі [M365Princess](https://github.com/JanDeDobbeleer/oh-my-posh/blob/main/themes/M365Princess.omp.json) тақырыбынан шабыттанған.
Сондай-ақ ол Starship ішінде каталогтар жолын ауыстырудың қалай жұмыс істейтінін көрсетеді.

![Pastel Powerline үлгісінің скриншоты](/presets/img/pastel-powerline.png)

### Алғышарттар

- Терминалыңызда [Nerd Font](https://www.nerdfonts.com/) қарпі орнатылған және қосылған болуы қажет (мысалда Caskaydia Cove Nerd Font қарпі қолданылған)

### Баптау

```sh
starship preset pastel-powerline -o ~/.config/starship.toml
```
