# Gruvbox Rainbow үлгісі

Бұл үлгі [Pastel Powerline](./pastel-powerline.md) және [Tokyo Night](./tokyo-night.md) үлгілерінен шабыттанған.

![Gruvbox Rainbow үлгісінің скриншоты](/presets/img/gruvbox-rainbow.png)

### Алғышарттар

- Терминалыңызда [Nerd Font](https://www.nerdfonts.com/) қарпі орнатылған және қосылған болуы қажет

### Баптау

```sh
starship preset gruvbox-rainbow -o ~/.config/starship.toml
```
