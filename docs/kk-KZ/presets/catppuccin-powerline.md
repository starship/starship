# Catppuccin Powerline үлгісі

Бұл үлгі [Catppuccin](https://github.com/catppuccin/catppuccin) палитрасын қолданатын [Gruvbox Rainbow](./gruvbox-rainbow.md) үлгісінің шағын өзгертілген нұсқасы болып табылады.

![Catppuccin Powerline үлгісінің скриншоты](/presets/img/catppuccin-powerline.png)

### Алғышарттар

- Терминалыңызда [Nerd Font](https://www.nerdfonts.com/) қарпі орнатылған және қосылған болуы қажет

### Баптау

```sh
starship preset catppuccin-powerline -o ~/.config/starship.toml
```

Әдепкі бойынша бұл үлгі Catppuccin-нің Mocha нұсқасын қолданады, бірақ `palette` мәнін өзгерту арқылы кез келген нұсқасын таңдай аласыз:

- `catppuccin_mocha`
- `catppuccin_frappe`
- `catppuccin_macchiato`
- `catppuccin_latte`
