# Bracketed Segments үлгісі

Бұл үлгі барлық кірістірілген модульдердің пішімін өзгертіп, әдепкі Starship сөздерінің ("via", "on", т.б.) орнына әр сегментті жақшалар ішінде көрсетеді.

![Bracketed Segments үлгісінің скриншоты](/presets/img/bracketed-segments.png)

### Баптау

```sh
starship preset bracketed-segments -o ~/.config/starship.toml
```
