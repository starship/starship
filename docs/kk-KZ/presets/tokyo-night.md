# Tokyo Night үлгісі

Бұл үлгі [tokyo-night-vscode-theme](https://github.com/enkia/tokyo-night-vscode-theme) тақырыбынан шабыттанған.

![Tokyo Night үлгісінің скриншоты](/presets/img/tokyo-night.png)

### Алғышарттар

- Терминалыңызда [Nerd Font](https://www.nerdfonts.com/) қарпі орнатылған және қосылған болуы қажет

### Баптау

```sh
starship preset tokyo-night -o ~/.config/starship.toml
```
